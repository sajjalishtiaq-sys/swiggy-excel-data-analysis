# 🍽️ Swiggy Sales Analysis Dashboard (Excel)

An interactive Excel dashboard that analyzes Swiggy food-order data across India, covering sales trends, top cities, food-type split, ratings and order volume.

---

## 📊 Dashboard Preview

![Swiggy Dashboard](swiggy%20dashboard.png)

---

## 🎯 Project Objective

To turn raw Swiggy order data into clear business insights:

- How much revenue is generated, and how does it trend over time?
- Which cities contribute the most sales?
- Do customers prefer Veg or Non-Veg food?
- Which days and quarters perform best?
- How are ratings and order counts distributed?

## 🔍 Key Insights

- **Top city:** Bengaluru leads with about ₹5.5M, followed by Lucknow (₹3.1M), Hyderabad (₹3.0M), Mumbai (₹3.0M) and New Delhi (₹2.8M).
- **Food type:** Veg contributes about 64% of sales (₹34M) vs Non-Veg at about 36% (₹19M).
- **Monthly trend:** Sales dip in February (about ₹6.3M) and recover through the following months, peaking around ₹6.8M.
- **Daily trend:** Saturday is the strongest day (about ₹7.8M); Monday and Tuesday are the weakest (about ₹7.4M).
- **Quarterly performance:** Q1 (₹19.7M) and Q2 (₹19.9M) are nearly equal. Q3 is lower (₹13.4M) because the data covers only July–August.
- **Ratings:** The average rating stays consistent at about 4.3 across all quarters.

## 🚀 How to Use

1. Download `Swiggy Data Excel.xlsx`.
2. Open it in Microsoft Excel.
3. Go to the **DASHBOARD** sheet.
4. Use the slicers (Food Type, Months, State) to filter the dashboard.

> Note: Map charts and slicers work best in Excel 2016 or later (Microsoft 365 recommended).
